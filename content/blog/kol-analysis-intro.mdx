## 背景

在社交媒体时代，KOL（Key Opinion Leader）的影响力越来越大。无论是投资决策还是产品选择，很多人都会参考 KOL 的观点。但问题是：

- 如何筛选出真正有价值的 KOL？
- 如何追踪他们的观点变化？
- 如何量化他们的影响力？

## 我的思路

我开发了一个 KOL 分析工具，主要包含以下功能：

### 1. 数据采集

自动采集 KOL 在各大社交平台的公开数据，包括：
- 发帖频率和时间分布
- 互动数据（点赞、评论、转发）
- 话题偏好和关键词

### 2. 影响力评估

基于多维度指标计算 KOL 的影响力评分：
- 受众活跃度
- 内容质量分
- 观点准确率（针对投资类 KOL）

### 3. AI 摘要

利用大语言模型对 KOL 的长文内容进行智能摘要，帮助用户快速获取核心观点。

## 技术实现

工具基于以下技术栈：
- **数据采集**：Python + Playwright
- **AI 分析**：Claude API
- **数据可视化**：React + Recharts
- **后端服务**：Next.js API Routes
